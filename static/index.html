2 如何在對話中呼叫 Subagent？

在 Antigravity 聊天視窗中，直接使用 @<slug> 即可指定專家！例如：
「請 @engineering-frontend-developer 幫我將這組按鈕重構為 Tailwind 元件並加入無障礙規範」
子代理將在獨立 Context 中執行，並將完成的成果回傳給主代理與你。

3 協作工作流規範 (Rule) 的威力

點擊「一鍵啟用 Rule」後，專案將寫入 .agents/rules/subagent-collaboration.md。這會強制 Main Agent 不得獨攬所有任務，遇到複雜需求時必須先主動向對應 Subagent 諮詢、拆解任務指派並進行測試驗證，確保程式碼品質與架構一致性！
